# Jutsue Mekodjio Bilios — Professional Portfolio & CMS

A professional, database-driven portfolio website and content management
system developed for **Jutsue Mekodjio Bilios**, IT Specialist, Health Data
Analytics professional, and Digital Entrepreneur based in Yaoundé, Cameroon.

The platform combines a modern professional portfolio with a secure
multi-admin Content Management System (CMS), allowing authorized
administrators to manage professional information, projects, experience,
education, achievements, certifications, gallery content, and contact
messages.

---

## 🎯 Project Objectives

The project aims to:

- Build a professional digital presence for Jutsue Mekodjio Bilios.
- Showcase his expertise, career, projects, education, and achievements.
- Provide a secure dashboard for managing website content.
- Allow multiple authorized administrators to manage the platform.
- Store dynamic website content in a MySQL database.
- Provide a scalable foundation for future features and improvements.
- Demonstrate professional software engineering practices.
